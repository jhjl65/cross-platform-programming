# Wavely — серверна частина (ЛР № 2)

REST API для треків аудіоплеєра: `GET/POST /api/tracks`, `GET/PUT/DELETE /api/tracks/:id`.

## Запуск

1. `npm install`
2. Створіть файл `.env` за зразком `.env.example` і вкажіть власний `MONGO_URI` (файл `.env` не потрапляє в git).
3. `npm run dev`

Запити для перевірки — у файлі `requests.http` (HTTP Client у WebStorm).
