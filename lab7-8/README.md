# Wavely — монорепозиторій

Аудіоплеєр для сну, відпочинку й концентрації з фоновим відтворенням і офлайн-режимом.
Одне спільне ядро з правилами, три клієнти: веб, десктоп і мобільний застосунок.

## Структура

```
lab7-8/
├── package.json          — корінь: npm workspaces, скрипти test, start:web, start:desktop
└── packages/
    ├── core/             — @wavely/core: спільна логіка без платформних API
    ├── web/              — веб-клієнт (HTML, CSS, JavaScript) і простий сервер
    ├── desktop/          — десктоп-клієнт Electron (головний процес, preload, рендерер)
    └── mobile/           — мобільний клієнт (React Native, Expo)
```

## Запуск

```
npm install
npm test
npm run start:web
npm run start:desktop
```

`npm test` запускає тести всіх пакетів: ядро — 26, десктоп — 8, веб — 6, мобільний — 3.

### Історія проєкту

**Назва:** Wavely.

**Проблема.** Застосунки для сну й фокусу часто платні, не працюють офлайн або не дають змішувати фонові звуки. Wavely зберігає бібліотеку звуків і позначає треки для прослуховування без інтернету на будь-якому пристрої.

**Моя роль.** Єдиний розробник: проєктування, реалізація серверної частини, клієнтів, спільного ядра, тестування і документування.

**Обраний стек і обґрунтування.**
- *Веб і Electron на JavaScript.* Одна мова для браузера і для десктопа: ядро пишеться один раз і імпортується в обидва клієнти.
- *React Native.* Мобільний клієнт на тій самій мові, зі спільною логікою через ядро.
- *npm workspaces.* Пакети в одному репозиторії, зміна ядра одразу доступна клієнтам без публікації.
- *Платформні адаптери.* Ядро не знає, де лежать дані, тому його можна тестувати в пам'яті і підключати до будь-якого сховища.
- *Node.js і `node --test`.* Тести без зовнішніх залежностей, швидкий запуск.

**Найскладніший кросплатформний виклик.** Одна логіка для трьох середовищ, які по-різному працюють із сховищем і вікном. Рішення: логіка в `@wavely/core`, платформа підключається через адаптер, а тести ядра працюють без браузера. Перевірено на практиці: зміна правила довжини назви з 100 на 50 символів одразу дала нове повідомлення у вебі й на десктопі без змін їхнього коду.

**Відоме обмеження.** Мобільний клієнт `App.js` автоматично не тестується, тільки адаптер. Веб і десктоп перевірено вручну в браузері та у вікні Electron.

### Здобуті знання та вміння

- **Знання:** архітектура крос-платформних застосунків (спільне ядро і адаптери), REST і GraphQL, автентифікація JWT, компонентний підхід у React і React Native, безпека Electron (contextIsolation, CSP, preload), монорепозиторій і npm workspaces.
- **Уміння:** створити API і підключити його до клієнта, написати спільний код, який запускається у вебі, на смартфоні й на комп'ютері, покрити логіку тестами, упакувати й опублікувати застосунок (Docker, GitHub).
